### ¿Qué es Git?
Git es un sistema de control de versiones dsitribuido que permite registrar los cambios realizados en los archivos de un proyecto. Facilita el trabajo colaborativo,permitiendo a múltiples desarrolladores trabajar en diferenctes ramas y fusionar sus cambios de manera eficiente.
